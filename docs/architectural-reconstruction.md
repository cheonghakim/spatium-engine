# 도면에서 건축 요소가 있는 3D 만들기

1. 도면을 불러오고 **축척 보정**으로 실제 거리를 지정합니다. 후보 감지는 미터 단위 크기를 사용하므로 축척에 영향을 받습니다.
2. **자동 벡터화**를 실행합니다. 기존 벽·방 외에 벽 사이 틈과 반복되는 계단 선을 후보로 제안합니다.
3. **검토 → 건축 요소 후보**에서 틈을 문·창문·통로로 지정하고 포함합니다. 계단은 폭·깊이·단수·높이·상행 방향을 확인합니다. 기본 높이는 도면에서 측정한 값이 아닙니다.
4. 문 틈을 연결해 찾은 방은 기본 제외되어 있습니다. 윤곽을 확인하고 포함하면 3D 바닥이 생깁니다. 벽을 수정하면 방과 요소 후보를 다시 검토해야 합니다.
5. **3D 미리보기**에서 결과를 확인한 뒤 확정합니다. 계단 후보를 포함하면 해당 단선 벽과 계단 안의 작은 방 조각은 대체됩니다. 확정 전체는 한 번의 실행 취소로 되돌릴 수 있습니다.

자동 감지되지 않은 요소는 **출입구(D)**로 배치하고 **속성**에서 종류를 바꿉니다. 위치·폭·높이·방향, 창문 하단 높이, 문 열림 각도, 계단 깊이·단수·상부 계단참을 편집할 수 있습니다. 문·창문은 가까운 벽 하나에 연결되며 연결 벽을 직접 지정할 수도 있습니다. 벽에서 멀어지면 독립 요소로 표시됩니다. 계단 공간은 공간 타입을 `stairs`로 바꾸고 높이·상행 방향·단수를 지정합니다.

방은 얇은 바닥으로, 벽은 별도 형상으로 표시합니다. 문은 개구부·문틀·문짝, 창문은 개구부·창틀·유리로 표시하며 상부 벽과 창문 아래 벽을 유지합니다. 겹친 개구부의 벽 제거 영역은 합집합으로 처리하지만 겹친 문틀은 직접 정리해야 합니다. 계단은 직선형이며 계단 공간은 지정된 윤곽 안에 단차를 생성합니다.

현재 인식은 규칙 기반 후보 제안입니다. 문 여닫이 호·창문 기호를 학습 모델로 분류하지 않으며, 사선·곡선 벽, 꺾이는 계단, 난간, 층간 바닥 개구부, 치수 문자 해석은 자동 복원하지 않습니다. 실제 도면 모음에 대한 인식 정확도 평가도 별도로 필요합니다. JSON에는 새 치수가 보존되고, 기존 프로젝트는 선택적 필드의 기본값으로 표시됩니다. GeoJSON에도 새 건축 치수가 포함됩니다.
